DPI Engine — Deep Packet Inspection System

Mar 2026
  • A Java-based PCAP packet analyser that walks raw capture files through three protocol layers — Ethernet → IPv4 → TCP/UDP — parsing headers by hand, byte by byte, with zero external libraries.
  • Parses the TLS handshake directly to pull out the SNI (Server Name Indication) hostname, which is enough to identify which of 20+ apps a connection belongs to without ever decrypting the traffic.
  • Tracks live connections with a 5-tuple flow tracker (source/destination IP, ports, protocol) feeding a rule engine that can block traffic at the IP, application, or domain level.
  • Built with no dependency on existing packet-parsing libraries — every layer, from Ethernet frames to TLS records, is decoded from scratch, which forced a genuinely low-level understanding of how the stack fits together.
